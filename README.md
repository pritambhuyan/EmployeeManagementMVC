# Employee Management System

This is an ASP.NET MVC application that performs full CRUD operations for managing employee records.  
The project uses Entity Framework (DB First), SQL Server, Bootstrap, and Razor Views.

## Features
- Add new employee
- Edit employee details
- Delete employee
- List employees with pagination
- Data validation
- Stored procedure support (if used)

## Technologies Used
- ASP.NET MVC
- C#
- Entity Framework (DB First)
- SQL Server
- Bootstrap
- Visual Studio 2022

## How to Run
1. Clone the repository
2. Update connection string in appsettings.json
3. Run migrations / update database (DB First)
4. Start project using IIS Express
